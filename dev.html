Code Examples

Exemple HTML

Basic structure of a Bootstrap card:

<div class="card">
  <div class="card-body">
    <h5 class="card-title">Title</h5>
    <p class="card-text">Content...</p>
    <button class="btn btn-primary">Action</button>
  </div>
</div>
Exemple CSS

Custom system.css variables:

:root {
  --surface: #c0c0c0;
  --button-highlight: #ffffff;
  --button-shadow: #808080;
  --window-title: #000000;
  --dialog-blue: #000080;
}

JavaScript Example

Bootstrap Modal initialization:

// Open a Bootstrap modal
const modal = new bootstrap.Modal(
  document.getElementById('myModal')
);
modal.show();

// Listen to the close event
modal._element.addEventListener(
  'hidden.bs.modal',
  () => console.log('Modal closed')
);

About

Bootstrap 5.3.8 + System.css Theme

This theme combines the power of Bootstrap 5 (grid, components, JavaScript) with the retro aesthetic of Apple System OS (1984-1991).

Benefits:
  • ✅ Tous les composants Bootstrap 5 disponibles
  • ✅ Grille responsive complète
  • ✅ JavaScript Bootstrap fonctionnel (modals, dropdowns, etc.)
  • ✅ Thème visuel system.css authentique
  • ✅ Composants additionnels system.css (.window, .title-bar, etc.)
  • ✅ Polices Chicago et Monaco incluses
